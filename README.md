## Featured project: Touchline AI

The portfolio retains Touchline's research case studies, methodology, model-card and required data attribution. Its descriptive scouting cohort and retrospective forecasting outcomes are not real-time recruitment recommendations.

Data credit: [openplay (Noah Bair)](https://github.com/nlbair/openplay) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

The public Touchline source showcase omits original raw datasets, private models, research history and unapproved data/QA redistribution. The owner-reported Streamlit app address is https://touchline-ai.streamlit.app/; public accessibility is separate from whether the code is publicly visible.

## Publishing

This is a static GitHub Pages website served from the repository root. Its GitHub Actions workflow uploads the static directory with no Jekyll, npm build, paid services or third-party front-end dependencies.

Keep repository links and claims grounded in the projects' published metadata. External demo availability is not guaranteed.

# Muhammad Rauf — Data Science & AI Portfolio

**Live website:** https://mrtrauf.github.io/  
**Alternative gallery link:** https://mrtrauf.github.io/gallery.html

An independent, responsive personal website for exploring open GitHub repositories. The homepage is a curated **project gallery**, not a Touchline AI research landing page.

## Experience

- Direct, clickable repository tiles with original project-specific SVG icons.
- Search by project name, tools and topic (press `/` to focus search).
- Accessible category filters for Football, Networks, Machine Learning, Research and IP Tools.
- Grid/list switcher; optional light/dark theme saved locally.
- Responsive desktop/tablet/mobile layout, keyboard focus states, reduced-motion support, and text-contrast-aware surfaces.
- Overview of background and contact links based on the publicly maintained GitHub profile.
- SEO, social metadata and Person JSON-LD.
- No paid assets, scraped player information, third-party fonts, analytics tracking, or external JS dependencies.

## Build and deploy

Pure static HTML/CSS/JavaScript: `index.html`, `gallery.html`, `style.css`, `site.js`, and `favicon.svg`.

- GitHub Pages publishes automatically on pushes to `main` using `.github/workflows/pages.yml`.
- No Jekyll build, package manager or runtime dependencies.
- Theme preference uses only browser local storage; no visitor tracking or backend.
- Project links are curated to existing public repositories. An external demo is not assumed accessible unless verified.
